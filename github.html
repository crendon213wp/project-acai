Build Your Next Website with Acai

Acai gives you a ready-to-use frontend development workflow so you can spend less time configuring your project and more time building websites.

Clone the repository, install the dependencies, run Gulp, and start building with a lightweight architecture powered by Bootstrap 5, Sass, BrowserSync, jQuery, Font Awesome, and reusable HTML partials.

View Acai on GitHub Read the Documentation

What You Get

Acai provides the core tools and project structure needed to begin modern frontend development without starting from an empty folder.

Gulp Build Workflow

Automate repetitive development tasks including Sass compilation, JavaScript processing, image handling, HTML processing, and live browser updates.

Reusable Partials

Build pages from reusable HTML components so navigation, headers, footers, and other shared elements can be maintained in one location.

Sass Architecture

Organize your stylesheets with Sass and let the Acai build workflow compile your source files into production-ready CSS.

Bootstrap 5

Start with a responsive, mobile-first layout system while retaining the freedom to customize or replace the default frontend stack.

BrowserSync

Preview your work locally with automatic browser reloading while you develop and refine your project.

CDN-First Development

Use popular frontend libraries through CDN delivery by default while keeping the project open to customization and expansion.

Clone. Install. Build.

You can have Acai running locally in just a few steps.

git clone https://github.com/crendon213wp/acai-framework.git

cd acai-framework

npm install

gulp

Once Gulp starts, your local development environment is ready for use.

Make Acai Your Own

Acai is a starting point, not a locked-down system. Use the architecture as provided or adapt it to the way you develop.

Customize

  • Modify the Sass architecture.
  • Create your own HTML partials.
  • Add your own JavaScript.
  • Install additional npm packages.
  • Change the Gulp workflow.

Remove

  • Remove Bootstrap if you do not need it.
  • Remove jQuery if your project uses vanilla JavaScript.
  • Replace CDN libraries with npm packages.
  • Remove unused build tasks.
  • Adapt Acai to your own development workflow.

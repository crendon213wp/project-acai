What Are Acai Components?

Acai components are the individual tools and systems that work together to create the framework's development workflow.

Acai is not one plugin or one library. It is an organized system built from several technologies, with each technology responsible for a specific job.

Gulp

Automates the development and build workflow.

HTML Partials

Make repeated HTML reusable.

Sass

Organizes and compiles the project's styles.

Bootstrap

Provides the default responsive UI foundation.

jQuery

Provides an optional JavaScript utility layer.

Font Awesome

Provides the default icon library.

The Simple Version

Acai is the system. These technologies are the tools that give the system its capabilities.

Gulp — The Build Engine

Gulp is the engine that automates Acai's repetitive development tasks.

Instead of manually processing every file, Gulp allows Acai to define tasks that can be run repeatedly and consistently. Gulp supports combining individual tasks into larger workflows using functions such as series() and parallel(). :contentReference[oaicite:0]{index=0}

What does Gulp do?

  • Processes HTML.
  • Compiles Sass.
  • Processes JavaScript.
  • Moves project assets.
  • Starts BrowserSync.
  • Watches files for changes.

Where is Gulp configured?

gulpfile.js

The Simple Version

You write the code. Gulp does the repetitive work.

HTML Partials — The Reuse System

Partials allow Acai to reuse the same HTML without copying it into every page.

Navigation, footers, metadata, documentation sections, and other repeated structures can live in their own files and be included wherever they are needed.

Example

@@include('partials/navbar.html')

During the build process, the include is processed and the reusable HTML becomes part of the generated page.

The Simple Version

Write it once. Include it wherever you need it. Update it once when it changes.

Sass — The Styling Engine

Sass gives Acai a structured way to write and organize CSS.

Acai uses Sass as the source for its custom styles. Gulp sends those Sass files through the Sass compiler and produces CSS that browsers can use.

Source

src/
└── scss/
    ├── base/
    ├── components/
    ├── utilities/
    └── application.scss

Output

dist/
└── css/
    └── application.css

Bootstrap also supports Sass customization, including variables, maps, mixins, and selective component imports. :contentReference[oaicite:1]{index=1}

The Simple Version

Sass is where you write your styles. Acai turns them into CSS.

Bootstrap — The UI Foundation

Bootstrap gives Acai a ready-made responsive foundation so developers can start building immediately.

Acai uses Bootstrap as a starting layer rather than treating Bootstrap as the framework itself. Developers can use its grid, utilities, components, and responsive system while adding their own styles and components on top.

Why Include Bootstrap?

  • Responsive layout foundation.
  • Prebuilt UI components.
  • Utility classes.
  • Responsive breakpoints.
  • Fast project development.

Can Bootstrap Be Changed?

Yes. Bootstrap supports extensive customization through Sass variables, maps, CSS variables, and selective imports. Developers can also remove unused components when using a Sass-based build. :contentReference[oaicite:2]{index=2}

The Simple Version

Bootstrap gives Acai a head start. Acai gives the developer control.

jQuery — The Optional JavaScript Layer

jQuery provides an additional JavaScript toolkit for projects that need it.

jQuery is not required by Bootstrap 5. Acai includes it as an optional development tool so projects that use jQuery or existing jQuery plugins can start with it available. Bootstrap 5 itself removed its jQuery dependency and uses regular JavaScript for its plugins. :contentReference[oaicite:3]{index=3}

Can I Remove It?

Yes. If your project does not need jQuery, remove its CDN reference and any project code that depends on it.

The Simple Version

jQuery is available when you need it. It does not have to stay when you don't.

Font Awesome — The Icon System

Font Awesome gives Acai an immediately available icon library.

Instead of creating or sourcing individual icons for every project, developers can use the included icon library throughout their interfaces.

Why Include It?

  • Large collection of icons.
  • Simple HTML implementation.
  • Useful for navigation and interface controls.
  • Easy to replace if another icon system is preferred.

The Simple Version

Font Awesome gives Acai a ready-to-use visual vocabulary.

BrowserSync — The Development Server

BrowserSync gives Acai a local environment for seeing changes while you develop.

When Acai starts BrowserSync, it serves the generated project locally and can automatically refresh connected browsers when watched files change. BrowserSync provides integration specifically for Gulp workflows. :contentReference[oaicite:4]{index=4}

Development URLs

Local:
http://localhost:3000

Does BrowserSync Affect Production?

No. BrowserSync is a development tool. It helps you build and test the website; it is not part of the website's production functionality.

The Simple Version

BrowserSync lets you see your work while you are building it.

npm — The Dependency Manager

npm manages the packages that give Acai its development capabilities.

Acai's package.json identifies the packages required by the project. Running npm install installs those dependencies into the project's node_modules directory.

Where Are the Dependencies Defined?

package.json

Where Are They Installed?

node_modules/

Can I Add More?

Yes. npm allows developers to install additional packages when a project needs new capabilities.

The Simple Version

package.json tells npm what Acai needs. npm gets the tools and installs them.

gulpfile.js — Acai's Instructions

The gulpfile tells Acai how its tools should work together.

Think of package.json as the list of tools Acai has and gulpfile.js as the instructions for using those tools.

HTML Task

Processes HTML files and reusable partials.

Styles Task

Compiles and processes Sass.

Scripts Task

Processes project JavaScript.

Images Task

Handles project images and assets.

package.json
      ↓
Available plugins
      ↓
gulpfile.js
      ↓
Acai workflow
      ↓
dist/

The Simple Version

npm provides the tools. gulpfile.js tells them what to do.

The Acai Philosophy

Every component has a job. Acai brings those jobs together without preventing developers from changing the system when their project requires something different.

Acai Utilities

Acai is built to be changed. The Utilities section shows you where the framework's tools live and how to modify them.

Want to upgrade a plugin, add a new feature, replace a dependency, or remove something you do not need? Start here. You do not need to rebuild Acai. You simply need to know where each part of the framework is configured.

Acai is an opinionated frontend development framework that lets you build dynamically and modularly while producing lightweight, deployable static websites and web applications.

Where Everything Lives

Each major part of Acai has a specific place in the project.

npm Dependencies

The package.json file controls Acai's npm packages.

If Acai uses an npm package, its dependency is recorded here. This is the first place to look when you want to upgrade, add, or remove an npm-based feature.

{
    "devDependencies": {
        "gulp": "^5.0.1",
        "gulp-sass": "^6.0.1",
        "sass": "^1.97.3"
    }
}

Simple Rule

If you want to change an npm dependency, start with package.json.

Gulp Plugins

The gulpfile.js determines how Acai uses its build plugins.

Installing a package does not automatically make it part of the build process. The Gulp workflow must use that package inside a task. Gulp is specifically designed around composing individual tasks into larger workflows. :contentReference[oaicite:0]{index=0}

const sass = require('gulp-sass')(require('sass'));
const cleanCSS = require('gulp-clean-css');
const terser = require('gulp-terser');

Add

Install the package, require it in gulpfile.js, then add it to the appropriate task.

Upgrade

Update the dependency and test the affected build task.

Remove

Remove the package from the project and remove its corresponding Gulp configuration.

CDN Dependencies

Acai keeps several frontend libraries outside the npm build system by loading them through CDN links.

These dependencies are typically found inside the appropriate HTML partials, particularly the head and JavaScript partials.

Bootstrap

Responsive layout and interface foundation.

jQuery

Optional JavaScript and DOM functionality.

Font Awesome

Icon library and interface icons.

To replace or remove a CDN dependency, locate its reference in the appropriate partial and update the markup rather than modifying generated files in dist.

JavaScript System

Acai keeps project JavaScript separate from the framework's HTML and styling systems.

Project scripts are stored in src/js/ and processed through the JavaScript task defined in gulpfile.js.

src/
└── js/
    ├── application.js
    └── modules/

Keep JavaScript simple when the project is simple. Add libraries or modules when the project actually needs them.

Asset Management

Acai keeps project assets organized and separates source assets from generated output.

Images

Store project images inside src/images/.

Source Files

Edit source assets instead of generated files.

Output

Gulp copies processed assets into dist/.

How to Upgrade a Feature

Upgrading Acai does not require rebuilding the framework.

  1. Identify the package or feature you want to upgrade.
  2. Locate its configuration inside package.json, gulpfile.js, or the appropriate partial.
  3. Update the dependency or configuration.
  4. Run the build workflow.
  5. Test the generated website before deployment.

Upgrade the part you need. You do not need to replace the entire framework.

How to Remove a Feature

Acai does not require you to keep features your project does not use.

Removing a feature usually means removing both the dependency and the code that uses it.

1. Dependency

Remove the package from package.json if it is npm-based.

2. Configuration

Remove its configuration from gulpfile.js or the appropriate partial.

3. References

Remove HTML, Sass, or JavaScript references that depend on it.

Run npm install, rebuild Acai, and test the project after removing a dependency.

The Acai Rule

Keep what you need. Change what you don't.

Acai is a starting point, not a locked ecosystem. The framework gives you an organized architecture, a working build system, and a practical technology stack so you can begin immediately.

As your project changes, Acai can change with it. Upgrade dependencies, add plugins, remove unnecessary features, modify the build process, or replace parts of the default stack.

Build It Your Way

Acai gives you the foundation. Your project decides what comes next.

Acai Frontend Framework

Lightweight frontend development without the unnecessary overhead.

Acai is a reusable frontend framework designed to help developers build responsive websites with a structured, automated workflow. Powered by Gulp, Sass, Bootstrap 5, BrowserSync, and reusable HTML partials, Acai handles the repetitive work so you can focus on building.

Acai Framework

Gulp Sass HTML Partials BrowserSync Bootstrap 5

Gulp Powered Frontend Development

Acai uses Gulp to automate the repetitive tasks involved in frontend development. Compile Sass, process JavaScript, optimize assets, assemble reusable HTML partials, and run a local development server from a single workflow.

Acai provides these tasks as part of its default Gulp workflow, allowing the same build process to be reused across projects.

Bootstrap 5, Ready When You Need It

Acai includes Bootstrap 5 as its default responsive UI foundation. Use its grid system, utilities, and components to build responsive layouts without creating common patterns from scratch.

Explore Acai Components

jQuery CDN Included

Need lightweight DOM manipulation, event handling, or legacy plugin compatibility? Acai includes jQuery through a CDN so it's available when your project needs it.

A Structured Sass Workflow

Acai uses Sass to make the project's styles easier to organize, customize, and maintain.

Modify variables, create reusable styles, organize your stylesheets, and compile everything through the Acai Gulp workflow. Your source styles stay readable during development while the build process handles the compiled CSS.

Learn About Acai's Sass Workflow

Font Awesome Icons

Acai includes Font Awesome through a CDN, giving your project access to a large library of scalable icons without adding another local icon asset library to the project.

Explore Icon Components

Reusable HTML Partials

Acai uses HTML partials for shared elements such as navigation, footers, metadata, and reusable components. Update a partial once and let the build process distribute the change wherever that partial is included.

Learn About HTML Partials

Modular Architecture

Acai separates source files, reusable components, styles, scripts, and assets into an organized project structure. This keeps individual pieces manageable while making them easier to reuse across multiple pages.

Explore the Project Structure

Developer Workflow

Acai follows a straightforward development cycle:
Develop → Compile → Preview → Optimize → Deploy

Write your source code, let Gulp handle the repetitive build tasks, preview changes through BrowserSync, and generate the files needed for deployment.

Learn the Acai Workflow

Prefer Your Own Stack?

Acai gives you a starting point, not a set of restrictions.

Bootstrap 5 is the default foundation, but you can customize the Sass architecture, modify the JavaScript, change the HTML structure, add your own components, replace dependencies, or remove the tools your project doesn't need.

Use Acai as provided, customize it to fit your workflow, or use its architecture as the foundation for something entirely your own.

Learn How to Customize Acai

Get Started with Acai

Getting started is straightforward. Clone the repository, install the project dependencies, and launch the Gulp development workflow.

From there, Acai gives you an organized frontend foundation with Sass, Bootstrap 5, reusable HTML partials, BrowserSync, and automated build tasks already configured.

Use Acai for landing pages, static websites, prototypes, documentation sites, portfolio projects, and other frontend projects where a lightweight development workflow makes sense.
